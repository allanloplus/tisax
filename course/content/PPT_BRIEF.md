# 實體課程簡報（PPTX）大綱撰寫規範

講師 Allan Lo 在實體課使用的 3 小時簡報（約 110–125 張）。線上教材比簡報完整，簡報負責「講重點、帶討論」，細節放在講者備忘稿（notes）。
語言：繁體中文（台灣用語），英文專有名詞保留。

## 輸出：JSON 檔 `{"slides":[ ... ]}`，每張投影片為下列其中一種 type

所有 type 都有 `notes`（講者備忘稿，120–350 字，Allan 的口吻：要講的重點、案例、提問互動、時間提醒），以及可選 `min`（預估講授分鐘數）。

1. 章節分隔頁
```json
{"type":"section","part":"PART 3","title":"資訊安全 第1章 政策與組織","subtitle":"1.1–1.6　14 個控制項","who":"allan","notes":"..."}
```
2. 控制項頁（最常用；一頁一個控制項，或把兩個很短的控制項放兩頁）
```json
{"type":"control","id":"1.3.2","title":"資訊分級與保護需求","q":"資訊資產依保護需求分級並管理的程度？",
 "must":["≤4 條，每條 ≤ 30 字"],"should":["≤3 條，每條 ≤ 30 字"],"high":["≤2 條，含（C/I/A），≤ 30 字；極高請以「極高：」開頭"],
 "practice":["≤3 條實務作法，每條 ≤ 26 字"],"audit":["≤3 條稽核重點／常見缺失，每條 ≤ 26 字"],"notes":"..."}
```
   - 條文精簡但不可失真；超過的細節寫進 notes。
3. 重點條列頁
```json
{"type":"bullets","title":"…（≤ 20 字）","bullets":["≤6 條，每條 ≤ 34 字"],"who":"allan 或 arale 或省略","notes":"..."}
```
4. 表格頁
```json
{"type":"table","title":"…","head":["欄1","欄2","欄3"],"rows":[["≤ 6 列","每格 ≤ 24 字",""]],"notes":"..."}
```
5. 流程步驟頁
```json
{"type":"steps","title":"…","steps":[{"t":"步驟名 ≤ 10 字","d":"說明 ≤ 30 字"}],"notes":"..."}   // 3–6 步
```
6. 卡片頁（3–4 張卡）
```json
{"type":"cards","title":"…","cards":[{"t":"卡片標題 ≤ 12 字","d":"說明 ≤ 50 字"}],"notes":"..."}
```
7. 隨堂測驗頁（每個大段落 1 題，帶動互動）
```json
{"type":"quiz","title":"隨堂小測驗","q":"題目 ≤ 60 字","options":["A","B","C","D（每個 ≤ 26 字）"],"answer":1,"notes":"解答與解析"}
```
8. 情境討論頁（案例研討，每個大段落 0–1 張）
```json
{"type":"case","title":"情境討論：…","scenario":"情境描述 ≤ 120 字","question":"討論題 ≤ 50 字","notes":"參考答案、Auditor 會怎麼判定"}
```
9. 金句／對話頁（ARALE 串場，用來轉場、帶氣氛，每段 0–1 張）
```json
{"type":"quote","who":"arale","text":"≤ 60 字的一句話","notes":"..."}
```

## 原則
- 內容來源：`/home/user/tisax/course/content/<key>.json`（已完成的線上教材，忠實於 ISA 2027.1）。不要創造原文沒有的要求。
- 每個控制項至少出現在一張 control 頁（Prototype Protection 的實體安全 8.2.x 可兩項一頁，但需用兩張 control 頁或 table 頁涵蓋）。
- 版面文字一定要短（簡報字級 14pt 以上），避免塞字；細節放 notes。
- 合法 JSON，`ensure_ascii=False, indent=1`，寫完用 python 驗證可載入，並檢查字數上限。
